How the ranking is measured
One number per model: the mean of its overall over the shared set — the 12 buildings every ranked model has run, with repeats averaged into the building first. Coverage is identical across rows by construction, so the rows are directly comparable; models that have not finished the shared set are not ranked here. Every other column on every tab is aggregated the same way, over that row's own buildings. The ± is that model’s own standard error: the deviation of its score from one building to the next, over the root of how many buildings it was ranked on. Repeats are averaged into the building before that is taken, so running one cell four times tightens the number rather than counting four times. It is blank where nobody has run that model twice, which is not the same as zero, and it is absent from the same set view altogether, because that view takes one run per building so that no row rests on more attempts than another. The # column is the position in the current sort, nothing more — most single steps of this table cannot be statistically separated. That is tested pair by pair on the buildings both of them ran — the difference building by building, which takes out how hard the building was, since that part is the same for both — and 12 of the 14 steps down this table do not survive it. With this few buildings, only the ends of the table are separated; that is the state of the evidence, not a fault in the table. Which buildings each row has, and which ones every row has, is in what each row is a mean over below.
How the chart is measured

The whisker through each dot is one standard error either way, and it is that model’s own: the deviation of its score from one building to the next, over the root of how many buildings it was ranked on. Repeats are inside those per-building scores already, averaged in before the mean is taken, so a cell run four times is one building’s worth of evidence with a tighter number on it. These bars are not all the same size — they run from 0.014 to 0.083 on this board — because what moves this score is which building far more than which afternoon. Where two dots are closer together than their bars are long, their order is not a result.

The solid line is the frontier: for every model on it, nothing beats it by more than this bench can measure — 0.027 on the score, the middle model’s standard error, and 15% on the cost, which is measured by running the same cell twice. A strict reading of “nothing cheaper scores higher” put a model on the line for costing two cents less than one scoring 0.079 above it, and two cents is not a decision anybody makes. Only the models on the frontier are named on the plot; every other point is a dot, and pointing at one says which model it is, what it is ranked on, and how far it moves.

The reasoning effort is part of the name — claude-opus-5 (high) is that model at its own default, because no lane has ever been given --effort and high is what the 5-series resolves to. A name with no bracket is a model that does not take the setting. Every setting is its own dot, and they are not joined up: the distance between one model’s settings is smaller than these bars, so two of them sitting apart is not yet evidence that thinking harder helped. Running the same cell again moves it by 0.106 on its own, and every run that was measured on is on the runs page.

Cost is the median of one run of that model, read off the agent CLI’s own ledger. Where it does not — the Gemini CLI reports tokens but no price — the run is priced from its own recorded tokens at the published list of 2026-08-25, cached prompt at the cached rate and thinking billed as output. Those rows carry an est. price tag, because an estimate and a bill are not the same fact.
