How to read these resultsScoring, comparison scope and reproducibility+

One output, one case

In This building mode, every position on the curve is that model’s score on the selected building. The adjacent viewer shows that same result. Reference images are observations, not ground-truth 3D meshes.

Keep the case set fixed

Common-set mean averages the same eight sample cases for every model. The thumbnail remains the selected building’s example; the inspector labels its individual score separately. Lines only connect releases within the same family.

Before publishing real results

Replace all sample records with measured results and verified release dates. Record the prompt, input views, agent scaffold, budget, run-selection policy and evaluation version. This prototype does not define BuildingBench’s scoring formula.

All 8 reference thumbnails come from the screenshot supplied in this conversation. No live benchmark API or actual GLB/glTF outputs are connected. Uncertainty estimates and repeated-run statistics are not available in this preview.
